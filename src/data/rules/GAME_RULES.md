# 🎯 키즈스톡 게임 기획 룰북

> 아이들이 하루 10~15분 플레이하며 경제를 자연스럽게 배우는 앱

---

## 📌 핵심 설계 원칙

| 행동 | 목적                             |
| ---- | -------------------------------- |
| 출석 | 재방문 유도                      |
| 퀴즈 | 핵심 학습 행동                   |
| 투자 | 핵심 앱 체험                     |
| 업적 | 뱃지 모으는 재미 → 장기 동기부여 |

- 보상 우선순위: **출석 > 퀴즈 > 투자**
- 업적 보상은 일반 보상보다 크게 (특별한 성취감)
- 아이들이 보상 체감을 자주 느낄 수 있어야 함

## 💰 투자 시스템

### 사이버머니 (money)

- 시작 금액: **100만원**
- 보상으로는 받을 수 없음 → **순수 투자로만 벌고 잃는 구조**
- 주식 가격은 **하루 1회 업데이트** (실시간 X → 도박 느낌 방지)

### 구매 / 판매 규칙

|           | 구매     | 판매           |
| --------- | -------- | -------------- |
| 횟수 제한 | 하루 1회 | 제한 없음      |
| 보상 지급 | 매번     | 하루 첫 판매만 |

> 판매를 자유롭게 두는 이유:
> "샀는데 떨어지네... 손절할까 버틸까?" 고민이 진짜 주식 체험이기 때문

### 파산 시스템

- money가 0원이 되면 **파산** 처리
- 레벨, 업적, 뱃지는 **유지** (리셋 없음 → 좌절감 방지)
- **키즈스톡 지원금 50만원** 자동 지급 후 재시작
- "파산했지만 키즈스톡 지원금을 받았어요! 다시 도전해봐요! 💪"

## 🗂 파일 구조

```
data/rules/
├── achievementRules.ts  → 업적 조건 + 뱃지 + 보상 (22개)
├── attendanceRules.ts   → 연속 출석 뱃지 기준
├── levelTitles.ts       → 레벨별 exp + 칭호 + 티어
├── missionRules.ts      → 활동 점수 규칙
├── progressRules.ts     → 중복 보상 방지 기준
└── rewardRules.ts       → 행동별 즉시 보상 수치
```

> - 규칙 파일은 수치만 관리, 실행 로직은 Context가 담당
> - 황금카드 기준 → levelTitles.ts
> - 업적/뱃지 기준 → achievementRules.ts
> - mock 데이터는 가짜 서버 데이터 ( TODO : Supabase 연동 시 제거 예정)
> - 계산 로직은 utils로 분리

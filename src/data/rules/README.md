🎯 핵심목표
👉 하루 플레이 10~15분
→ 하루 평균 120~180 코인
→ 1~2일에 아이템 1개 구매
→ 레벨 5 도달 약 1~2주

✅ 아이들이 보상 체감을 느끼게 해야 함.

- 퀴즈 = 핵심 학습 행동
- 투자 = 핵심 앱 행동
- 출석 = 재방문 유도
- 출석 > 퀴즈 > 투자 순으로 보상지급
- 업적 보상 밸런스
  업적은 큰 보상이어야 함.

✅ 레벨 밸런스
(초반 빠르게 성장, 후반 느려짐)

- 1 → 0
- 2 → 100
- 3 → 300
- 4 → 700
- 5 → 1500

✅ 미션 점수

- BUY_STOCK: 1
- QUIZ_CORRECT: 2
- ATTEND_TODAY: 1

✅ 출석 보상

- DAILY_COIN: 20,
- WEEK_BONUS: 50,

✅ 하루 예상 보상

- 출석(20) - 퀴즈 3개(15) - 투자 3번(15) - 판매 1번(5)
  👉 업적 / 미션 포함하면 하루 80 ~ 150 코인

🔹 퀴즈

- 반복 가능 → 코인 적게
- 스트릭은 보너스
  🔹 투자
- 단순 매매는 적당히
- 일정 횟수 이상에서 보상 큼
  🔹 수익률
- 핵심 재미 요소 → 보상 크게
- 코인 + 점수 + 경험치 모두 지급
  🔹 실패
- 게임이 멈추지 않게
- 경험치 보상

-
- 황금 카드 기준 → 레벨 기준

# 🪙 kidsStock

> 어린이를 위한 주식 체험 금융 교육 앱

📅 개발 기간: 2026.01.17 ~ 진행 중

---

## 기획 의도

아이들이 주식을 '돈벌이'가 아닌 '경험'과 '이해'의 관점에서 접할 수 있도록 설계한 어린이용 주식 체험 앱입니다.

실제 돈이 아닌 가상 사이버머니(100만원)를 사용해 투자 흐름, 가격 변동, 기다림과 선택의 개념을 게임처럼 자연스럽게 경험할 수 있습니다.

## 주요 기능

### 📈 주식 마켓

- 모크 데이터 기반 주식 리스트
- 주식 상세 페이지 (차트 + 아이 눈높이 설명)
- 하루 1회 구매 제한 (기다림도 투자 경험)
- 판매는 제한 없음 (손절/버티기 의사결정 경험)
- 주가는 하루 1회 업데이트 (실시간 X → 도박 느낌 방지)

### 💰 포트폴리오

- 보유 주식 목록 및 평균 매수가 계산
- 총 자산 실시간 계산 (현금 + 주식 평가액)
- 파산 시 키즈스톡 지원금 50만원 지급 후 재시작

### 🏆 업적 / 뱃지 시스템

- 22개 업적 (COMMON / RARE / LEGEND 티어)
- 투자 / 자산 / 퀴즈 / 뉴스 / 출석 / 레벨 카테고리
- 업적 달성 시 팝업 알림 + 보상 자동 지급

### 🎮 레벨 시스템

- 경험치(exp) 기반 자동 레벨 계산 (10단계)
- 레벨별 칭호 부여 (🐣 투자 새싹 → 👑 투자 마스터)
- 경험치 게이지 UI 제공

### 📅 출석 / 퀴즈

- 매일 출석 체크 + 연속 출석 보너스
- 퀴즈 정답 시 코인 / 경험치 / 점수 보상
- 중복 보상 방지 처리

### 👥 커뮤니티

- 활동 점수 / 업적 수 기반 랭킹
- 친구 추가 / 피드 기능

## 상태관리 구조

```
Context
├── UserContext        → 유저 정보 단일 출처 (exp, coin, level 등)
├── TradeContext       → 거래 기록 원본 (BUY / SELL)
├── PortfolioContext   → 거래 기록 기반 파생 데이터 (보유현황, 총자산)
├── RewardContext      → 보상 지급 단일 창구
├── AchievementContext → 업적 조건 감시 + 보상 지급
├── QuizContext        → 퀴즈 상태
├── WalletContext      → 코인/머니 관리
└── UIContext          → 팝업 등 UI 상태
```

---

## 구현 포인트

**Context 의존성 설계**

- 순환 참조 방지를 위해 `giveReward`를 파라미터로 주입하는 패턴 적용
- 저장(localStorage)은 UserContext 단일 출처에서만 담당

**업적 시스템**

- 조건 함수(`condition`)를 데이터로 관리해 Context 로직과 분리
- 상태 변화 감지 시 자동으로 조건 체크 → 보상 지급 → 팝업

**보상 밸런스**

- 행동별 보상은 `rewardRules.ts` 단일 파일에서 관리
- 하루 기본 플레이(출석+퀴즈+투자) 시 약 80~150 코인 획득
